FRIEND SUGGESTION MINI-SYSTEM

PROJECT DESCRIPTION:
This project is a student networking application developed using Python, Flask and SQLite.

FEATURES:
1. Student registration and login.
2. Search for students.
3. Send friend requests.
4. Accept friend requests.
5. Suggest friends based on mutual connections.
6. Display mutual friends.
7. Find the shortest connection path using BFS.
8. Create student posts.
9. Display the student network.

TECHNOLOGIES USED:
- Python
- Flask
- SQLite
- HTML
- CSS
- Graph Theory

DISCRETE MATHEMATICS CONCEPTS:
1. Graph Theory
2. Vertices and Edges
3. Adjacency Lists
4. Sets and Set Intersection
5. Relations
6. Breadth-First Search (BFS)
7. Shortest Path
8. Degree of a Vertex

HOW TO RUN THE PROJECT:

STEP 1:
Open the project folder in VS Code.

STEP 2:
Open the terminal.

STEP 3:
Install the required package:

python -m pip install -r requirements.txt

STEP 4:
Run the application:

python app.py

STEP 5:
Open your browser and visit:

http://127.0.0.1:5000

STEP 6:
Register student accounts and test the application.

DATABASE:
The SQLite database is automatically created when the application starts.
